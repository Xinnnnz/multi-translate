### ✨ Features
- **Simultaneous Multi-Language**: Translates into Swedish (🇸🇪), English (🇬🇧), and Chinese (🇨🇳) all at once.
- **Tri-Directional Live Sync**: Type in *any* of the 3 panels—the other two sync automatically in real time.
- **Pinyin with Tone Marks**: Chinese translations include romanization/pinyin readings (e.g., `Nǐ hǎo, jīntiān zěnmeyàng?`).
- **Key Vocabulary & Technical Breakdown**: Interactive chips for technical terms (*debounce, throttle, programvaruteknik*).
- **Text-to-Speech (TTS)**: Listen to natural pronunciation in any language.
- **Export & History**: Export translations to Text, JSON, or CSV, with locally saved translation history.
